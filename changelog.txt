legendarysurvivaloverhaul 1.20.1 Changelog
====

This file combines two separate release lines for the 1.20.1 build of
LegendarySurvivalOverhaul:

- Unprefixed versions (e.g. "2.4.7") are carried over from the original
  Forge 1.20.1 mod's changelog, as of the point the Fabric port branched
  off. That Forge line is no longer updated here.
- "v"-prefixed versions (e.g. "v2.3.0") are the Fabric port's own,
  independently-numbered SemVer (https://semver.org/) releases. The
  Fabric port restarted numbering at v1.0.0 rather than continuing the
  Forge mod's version numbers, since it is a separate codebase/runtime
  (Fabric instead of Forge) with its own compatibility guarantees. See
  docs/wiki/Releases-and-Versioning.md for the full SemVer policy and
  docs/Fabric-Port-Wiki.md for the detailed per-build port history,
  including the pre-SemVer "v1.20.1-2.4.7-fabric.N" legacy prereleases.

== Fabric port (SemVer) ==

v3.2.0
====
Wetness keeps its saturation-scaled target temperature offset and now
multiplies cooling-only temperature steps by 1.5 in every biome by default.
Configure wetCoolingRateMultiplier in temperature.toml or the optional
Fzzy editor (1 restores normal speed). Warming is unchanged, and cooling
clamps at the target. Stacks multiplicatively with IW snowstorm cooling.

Added standalone crimson and warped lilies adapted from Scorchful, with
natural crimson/warped forest patches. Moist substrate refills their water:
nylium/rooted dirt is required in ultra-warm dimensions. Full crimson
lilies burst and soak players; full warped lilies fill bottles/canteens.
Water bottles/canteens can refill crimson lilies.

Replaced winter clothing visuals/names with Frostiful's non-armored fur
suit while preserving snow_* IDs, recipes, armor/cold values and durability.
Added craftable ice skates with Frostiful-style ice gliding, sprinting,
sneak braking, off-ice walking penalty and blade rendering.

Imported/adapted Scorchful/Frostiful portions remain LGPL-3.0 with bundled
attribution and license texts. Neither mod nor Thermoo is required.

v3.1.0
====
Added optional support for Atlasroar's Immersive Weathering 2.5.0+ storms.
Exposed snowstorms drive temperature toward frostbite at twice the normal
rate and apply Cold Hunger; Hot Drink blocks these storm penalties.
Sandstorms drive temperature toward heatstroke at twice the normal rate
and apply Heat Thirst; Cold Drink blocks these storm penalties.

Shelter requires all nine columns in a centered 3x3 area to have
sky-blocking cover within 10 blocks above the player's eye block.
Higher roofs and uncovered corners do not count. Freezing-wind hits
separately apply Cold Hunger for 200 ticks (10 seconds), even with Hot Drink.
Existing cold/heat immunity remains respected. Finite wind hunger survives
normal temperature cleanup and overlapping storm exposure.

The integration has its own default-enabled temperature config toggle,
immersiveWeatheringStormsEnabled, and requires the temperature system.
It is inert without the supported IW build; no weather mod is bundled or
required. Existing ambient temperature secondary-effect toggles remain
separate from the integration's storm penalties.

v3.0.0
====
Removed the requested obsolete mod compatibility datapacks and Quark asset
overrides, along with their generators and legacy default registrations.
Removed unused Forge loot/biome modifiers and migrated retained recipes to
Fabric-compatible tags and NBT ingredients. Farmer's Delight Refabricated
and Fabric BetterEnd data are retained.

Refreshing, Purity and Reservoir apply only to regular and large canteens.
All three are treasure enchantments: available as loot books, not through
the enchanting table or villager trades. Level-based loot generation no
longer applies these enchants to unrelated breakable equipment.

Trinkets and Fzzy Config are strongly recommended, not required. Fabric
Language Kotlin is also optional for LSO. Trinkets adds accessory slots
when installed; supported held-item effects still work without it.
Existing head-equipment checks remain, but no new vanilla equip path for
the Respirator is added. Configuration files work without Fzzy Config;
installing Fzzy Config adds its editor and requires its own Kotlin dependency.

v2.8.1
====
Fixed freezing and heat overlays washing out the screen white or yellow.
Both effects now explicitly enable alpha blending so texture transparency
and the existing fade levels are respected.

v2.8.0
====
Added hydration datapack support for drinks (and a few related
foods) from eight optional mods: Farmer's Delight Refabricated,
HerbalBrews, Vinery, Meadow, Farm & Charm, Bakery, Candlelight, and
Brewery. Each mod's values are shipped as plain reloadable JSON
under data/<mod id>/thirst/consumables/ (and data/<mod id>/thirst/blocks/
for drinkable blocks like Brewery's kegs/taps and Candlelight's
kitchen sinks), matching LSO's existing cross-mod Thirst data
format. This is a pure datapack: there is no compile-time dependency
on any of the eight mods, and every entry is only read when LSO
detects the matching mod namespace is loaded (FabricLoader
isModLoaded), so nothing changes with those mods absent. Values were
ported from LSO's own pre-existing (compatibility) value set for
these same mods. Bakery has no dedicated beverages, so it only
receives a small hydration amount on its Pudding Slice, its moistest
item.

v2.7.0
====
Added explicit compatibility for WandererZ, the LevelZ continuation
mod (merges LevelZ's level/skill system with Jobs, RPG Difficulty,
Tiered, Party, and a bundled food-spoilage system internally named
SpoiledZ, under the single "wandererz" mod id). LSO's existing
LevelZ death-respawn max-health timing fix was already implemented
generically (it reacts to any mod's AFTER_RESPAWN-timed attribute
recomputation rather than a specific mod ID), so it already covered
WandererZ's level-based max-health bonus with no code changes
required; this is now documented explicitly. Also shipped a
defensive datapack tag (data/spoiledz/tags/items/non_spoiling_items.json)
explicitly excluding all of LSO's drink items (Canteen, Large
Canteen, the Juice line, Purified Water Bottle, Water Plant Bag)
from WandererZ's bundled SpoiledZ food-spoilage system, guaranteeing
LSO's own Thirst-driven drinks never integrate with that spoilage
mechanic.

Replaced the repo's stock, unedited Minecraft Forge MDK
LICENSE.txt/CREDITS.txt template with a project-specific LGPL-2.1
license and accurate credits: Sfiomn (original author) and Atlasroar
(Fabric port maintainer) under LGPL-2.1, Miner's Lung
(Petra/gamma-delta, MIT) as the original source of the integrated
Thin Air assets, Fuzs for continued Thin Air maintenance, and
Penguin_Spy's Thinner Air (MPL-2.0) credited for inspiration only
(no code reused). Updated THIRD_PARTY_NOTICES.md and the wiki
Credits and Licenses page to match.

Modernized the GitHub issue templates: bug report, feature request,
and compatibility request templates now explicitly state that
support is only provided for Minecraft 1.20.1 on Fabric, use
current Fabric-appropriate fields instead of stale Forge-era ones,
and include a dedicated screenshots/video section. Added a
config.yml disabling blank issues and linking the supported-version
note.

v2.6.4
====
v2.6.3 shipped the "added_desc" tooltip keybind unbound by default, but
that alone did not fix the Left Shift hijack for existing installs:
Minecraft persists bound keys by name in options.txt, so anyone who
had already launched the game kept the old saved "Left Shift"
binding regardless of the new default. v2.6.4 adds a one-time
client-side migration (gated by a marker file) that detects the
saved added_desc keybind still pointing at Left Shift, clears it to
unbound, and resaves options.txt, so the hijack is actually lifted on
upgrade without requiring players to manually rebind it in Controls.

v2.6.3
====
Fixed Left Shift being hijacked: the "added_desc" tooltip keybind
(used by Thermometer/Coat item descriptions) defaulted to Left Shift,
but Minecraft's KeyMapping system only routes key-down/up events to a
single binding per physical key. That silently starved vanilla sneak
and any other mod/custom keybind also bound to Left Shift. The
keybind now ships unbound by default; assign it yourself in Controls
if you want the Shift-to-expand tooltip behavior. No other behavior
changes.

v2.6.2
====
Added "Uses:" text to the Sun Fern, Ice Fern and Water Plant
seed/leaf/crop item descriptions (lore.legendarysurvivaloverhaul.*
lang entries), so holding Ctrl with Item Descriptions installed, or
scanning them with Field Guide, now tells players what each plant is
used for (e.g. Warm String, Cold String, drinkable Water Plant Bags).
Text-only change; no code or recipes modified.

v2.6.1
====
Replaced the Field Guide "LSO Flora" category's tab icon. v2.6.0
shipped a standalone hand-drawn placeholder icon; this is now a
sepia-toned recolor of the actual Sun Fern Leaf item sprite (silhouette
preserved, colors remapped to Field Guide's own sepia tab-icon
palette), so the tab visually matches the mod's built-in categories
while still not altering the real in-game item texture.

v2.6.0
====
Added compatibility for several client-side utility mods. Item
Descriptions / Mod Descriptions: LSO now ships its own
`lore.legendarysurvivaloverhaul.*` lang entries for every registered
item and block, so Ctrl-hover descriptions work out of the box with no
dependency or separate resource pack needed. Field Guide: added a
built-in "LSO Flora" datapack category (auto-populated with Sun Fern,
Sun Fern (Gold), Ice Fern and Water Plant crops) with its own
hand-styled tab icon matching Field Guide's sepia icon palette; this
only activates when Field Guide is installed. Immersive Overlays:
confirmed LSO's public TemperatureUtil API already fully supports their
thermometer compat class, but it is currently unreachable on Fabric
1.20.1 due to an upstream Stonecutter build-configuration gap in
Immersive Overlays itself (not fixable from LSO's codebase). Confirmed
in-game.

v2.5.0
====
Added HardcoreLite-inspired Enchanted Golden Apple and death heart-loss
mechanics. Eating an Enchanted Golden Apple specifically now grants a
dedicated Shield Health bonus (default 2 Shield Hearts) and repairs
Heart Containers (default 1), distinct from the generic vanilla-
Absorption override used by other Absorption sources. Death now removes
1 Heart Container by default, down to a configurable floor (default 1
Heart Container / 2 health); unlike the reference mod, LSO never forces
Spectator mode. Both mechanics are fully config-driven and reuse LSO's
existing delta/modifier-based max-health system, preserving LevelZ
compatibility; LevelZ's level-based health floor intentionally takes
precedence over LSO's floor. Fixed an ordering race so the death
heart-loss floor check always reads the final, LevelZ-combined max
health. Confirmed in-game with and without LevelZ installed.

v2.4.0
====
Added LevelZ mod compatibility: LSO's health overhaul already stacked
correctly with LevelZ's level-based max-health bonus by design, but the
death-respawn full heal could snapshot an incomplete max health if it
ran before LevelZ reapplied its bonus. The death-respawn heal is now
deferred to the player's next server tick so it always reflects the
final combined max health, regardless of mod load order. Confirmed
in-game: the LevelZ health bonus remains stable across death/respawn.

v2.3.0
====
Enabled datapack-only biome overrides while preserving native biome
climates (no matching Fabric mod ID required). Added optional
VanillaBackport sulfur-cave ambient YELLOW air. Equipped Respirators now
block new Nausea from any source, replacing the old upstream-specific
gas interception, with a descriptive tooltip. LSO - Air now has 27
controls; 259 settings across nine configs. Supersedes v2.3.0-beta.1.

v2.2.0
====
Added the LSO - Trinkets config: nine controls covering eight
accessories, with a tag-override switch, multiple/empty slot lists, and
missing-slot warnings. Equipped items are never force-relocated or
deleted; the Respirator is excluded. Total: 257 settings across nine
configs. Supersedes v2.2.0-beta.1.

v2.1.0
====
Added the dedicated LSO - Air config: 25 controls, including seven
fields moved from Common plus 18 new controls for dimension/height
overrides (opt-in), breathing rates, equipment wear, and bladder
behavior. Existing Common values migrate automatically. Total: 248
settings across eight configs. Supersedes v2.1.0-beta.1.

v2.0.0
====
Breaking: migrated configuration from Forge Config API Port to Fzzy
Config (requires Fabric Language Kotlin). All 230 options are editable
in-game via Mod Menu or /configure, and server configs sync to clients.
Existing 1.x config files are migrated automatically, keeping
.forge-backup copies. No gameplay changes. Supersedes v2.0.0-beta.1.

v1.0.0
====
First SemVer release. Validates the Thin Air air-quality system,
Safety Lanterns, Signal Torches, Air Bladders, Soulfire Bottles,
Respirator, and Turtle Helmet protection across the Overworld, Nether,
and End. Renames the vanilla Water Breathing effect/potions to "Free
Breathing". No gameplay changes from the legacy .30 build; only the
version scheme and jar name changed.
