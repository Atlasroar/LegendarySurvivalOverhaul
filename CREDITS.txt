Legendary Survival Overhaul: Credits

This file lists the people and projects Legendary Survival Overhaul (LSO)
builds on or was inspired by. It replaces the previous CREDITS.txt, which
was the unedited default Minecraft Forge MDK template credits file and had
no connection to this mod. See LICENSE.txt for license terms and
docs/wiki/Credits-and-Licenses.md for the full, versioned attribution and
license-boundary breakdown (which license covers code vs. which assets are
separately authorized, etc.).

== Original author and maintenance ==

Sfiomn created the original Legendary Survival Overhaul. This repository
is a Fabric 1.20.1 port maintained by Atlasroar, built on that original
work and licensed under LGPL-2.1 per LICENSE.txt.

== Air quality subsystem ==

- Petra (gamma-delta) authored the original Thin Air mod and Miner's Lung,
  both MIT licensed.
  https://github.com/gamma-delta/MinersLung
- Fuzs (@heyitsfuzs) maintains the continued Thin Air project and its
  assets; LSO's integrated air-quality assets were used here under express
  authorization from Fuzs, independent of the MIT source license.
  https://github.com/Fuzss/thinair
- Penguin_Spy's Thinner Air (Mozilla Public License 2.0) is credited for
  inspiring some of LSO's air-quality ideas. No code from Thinner Air is
  reused in this project, so its MPL-2.0 terms impose no redistribution
  obligation here; this is an attribution-only credit.
  https://codeberg.org/Penguin_Spy/thinner_air

== Health and progression ==

- PeteMC's HardcoreLite inspired the Enchanted Golden Apple shield-health/
  heart-container-repair bonus and death heart-loss mechanics (v2.5.0+).
  LSO implements its own logic on its existing systems; no HardcoreLite
  code is reused.
  https://github.com/MC-Mods-Pete/HardcoreLite

== Health bar rendering ==

- Fuzs (@heyitsfuzs)'s Overflowing Bars (Mozilla Public License 2.0) is
  adapted for LSO's optional Overflowing Bars HUD spacing support, with
  authorized reuse of its icon sheet.
  https://github.com/Fuzss/OverflowingBars

== Accessories/trinkets ==

- Emily (emilyploszaj) and contributors author Trinkets (MIT License),
  which LSO's accessory slots integrate with.
  https://github.com/emilyploszaj/trinkets
